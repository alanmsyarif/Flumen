# Roadmap

The milestone plan supersedes the original version-based convergence roadmap.

- **0.0.2 / M0-M1:** repaired static graph and transactional rebuild; stationary-surface animated particles, drag, detachment, collision, volume accounting, and native bake. See the implementation status for evidence and limitations.
- **M2 (not implemented):** reciprocal merging, bounded cohesion, persistent wetness, bounded historical trails, and coating display. Numerical conservation and memory gates must pass before release.
- **M3 (not implemented):** fixed-topology moving/deforming surfaces, material correspondence, inherited velocity, transported appearance, and topology invalidation. Correspondence feasibility is a prerequisite.

Detailed tasks and acceptance conditions: [implementation plan](superpowers/plans/2026-09-24-geometry-nodes-drips.md). Paper phenomena are inspiration; solver equivalence is not a goal of this Geometry Nodes approximation.
